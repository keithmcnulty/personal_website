# personal_website

Keith McNulty's personal site. Everything public lives in `docs/`, which GitHub Pages serves.

- `docs/index.html`, `docs/style.css` and `docs/script.js`: the site
- `docs/assets/`: web-sized images
- `docs/.nojekyll`: tells GitHub Pages to serve the files as-is

Preview locally: `python3 -m http.server -d docs` then open http://localhost:8000
